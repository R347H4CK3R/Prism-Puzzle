# Privacy
Prism Puzzle's source contains no analytics, advertising, accounts, or network service integration. Puzzle progress is stored locally in the app's WebView storage. The in-app Erase local progress control removes that saved puzzle state. Uninstalling the app removes its app-local data according to platform behavior. Android backup is disabled; iOS system backups may retain app data under the device owner's settings. No publisher server receives puzzle data.

This statement describes the current source. Before store submission, the owner must verify the signed release and provide a public support/privacy contact.
